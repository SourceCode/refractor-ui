## Epic E10: MultiSelectCombobox Token Chip Vertical & Horizontal Centering

### `REF-5521` — Replace Unicode `×` glyph with geometrically centered `<X />` icon in `MultiSelectCombobox`
- **Target File:** `packages/core/src/MultiSelectCombobox/MultiSelectCombobox.tsx` (lines 4 and 337–357)
- **Root Cause:**
  The dismiss button inside each selected emerald pill rendered `<span aria-hidden="true" className="leading-none text-sm">×</span>`. Across system sans-serif fonts, the Unicode multiplication sign `×` has an asymmetric vertical ink offset below the line-box midpoint, causing the close button to appear lower than the adjacent token text (`Optical Glass`, `React 19 Ref`).
- **Reference Solution Code:**
  ```tsx
  // packages/core/src/MultiSelectCombobox/MultiSelectCombobox.tsx
  import { Check, ChevronDown, Plus, X } from 'lucide-react';

  // Selected token pill:
  <span
    key={tokenValue}
    data-slot="token-chip"
    className="prism-emerald inline-flex items-center gap-1.5 h-7 pl-3 pr-1.5 rounded-full text-xs font-medium leading-none text-white max-w-full"
  >
    <span className="truncate leading-none">{tokenLabel}</span>
    <button
      type="button"
      disabled={disabled}
      aria-label={`Remove ${tokenLabel}`}
      onClick={(e) => {
        e.stopPropagation();
        removeToken(tokenValue);
      }}
      className="prism-focus-ring w-4 h-4 p-0 rounded-full inline-flex items-center justify-center text-white/95 enabled:hover:bg-black/15 cursor-pointer disabled:opacity-50 disabled:cursor-not-allowed shrink-0"
    >
      <X
        aria-hidden="true"
        className="w-3 h-3 block shrink-0 prism-contain-box"
        strokeWidth={2.5}
      />
    </button>
  </span>
  ```
- **Acceptance Criteria:**
  - Pill container uses `inline-flex items-center h-7 leading-none`.
  - Label span uses `truncate leading-none`.
  - Dismiss button uses `w-4 h-4 p-0 inline-flex items-center justify-center shrink-0` wrapping `<X aria-hidden="true" className="w-3 h-3 block shrink-0 prism-contain-box" strokeWidth={2.5} />`.
  - Zero raw Unicode `×` glyphs remain in token chip remove buttons.

### `REF-5522` — Add Token Chip Alignment & Icon Regression Tests
- **Target File:** `packages/core/src/MultiSelectCombobox/MultiSelectCombobox.test.tsx`
- **Reference Test Code:**
  ```tsx
  it('renders centered SVG X icons with equal horizontal/vertical flex alignment inside token chips', () => {
    render(
      <MultiSelectCombobox
        label="Component Capabilities & Tags"
        options={SAMPLE_OPTIONS}
        defaultValue={['crystal', 'emerald']}
      />
    );
    const removeBtn = screen.getByRole('button', { name: 'Remove Crystal Glass' });
    const chip = removeBtn.closest('[data-slot="token-chip"]');
    expect(chip).toHaveClass('inline-flex', 'items-center', 'leading-none');
    expect(removeBtn).toHaveClass('inline-flex', 'items-center', 'justify-center', 'p-0');
    const svg = removeBtn.querySelector('svg');
    expect(svg).not.toBeNull();
    expect(svg).toHaveClass('w-3', 'h-3', 'block', 'shrink-0', 'prism-contain-box');
    expect(removeBtn.textContent).toBe('');
  });
  ```
- **Acceptance Criteria:**
