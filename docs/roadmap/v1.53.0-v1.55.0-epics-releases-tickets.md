## Release `v1.53.0` — Motion, Gestures, Scroll & Animated Media

### Epic E1: Core Motion Engine & Layout Primitives
- **`REF-5301` — Physics-Driven Spring Solver & CSS `linear()` Compiler (`packages/core/src/motion/springPhysics.ts`)**
  - Implement deterministic RK4/semi-implicit spring simulation (`simulateSpring`, `evaluateSpringAt`) supporting `stiffness`, `damping`, `mass`, `velocity`, `restDelta`, and `restSpeed`.
  - Implement `compileSpringToCssLinear(config, samples?)` to emit zero-runtime CSS `linear(...)` easing functions and exact settle duration in milliseconds for hover/micro-interaction states.
- **`REF-5302` — Hardware-Accelerated Hybrid Animation Engine (`packages/core/src/motion/hybridEngine.ts`)**
  - Implement `animateHybrid(element, keyframes, options)` offloading compositor-safe properties (`transform`, `opacity`, `clip-path`, `filter`) to WAAPI `element.animate()` and `ScrollTimeline` when supported, with automatic rAF/calm fallback.
  - Export capability probes (`supportsWaapi`, `supportsScrollTimeline`, `isCompositorProperty`).
- **`REF-5303` — Scale-Corrected Layout Animations (`packages/core/src/LayoutMotionBox/`)**
  - Build `LayoutMotionBox` (`layout`, `layoutDependency`, `borderRadiusPx`, `shadowElevation`, `transition`) using FLIP measurement (`getBoundingClientRect`) and inverse-scale border-radius (`computeScaleCorrectedRadius`) + shadow counter-correction (`computeScaleCorrectedShadow`) so thick glass pills and cards never stretch or distort mid-transition.
- **`REF-5304` — Shared Element Transitions (`packages/core/src/SharedElementTransition/`)**
  - Build `SharedLayoutProvider` + `SharedElementTransition` (`layoutId`, `transition`, `borderRadiusPx`) capturing departing element geometry in a keyed layout registry and smoothly morphing arriving elements across view/tab/modal/palette transitions.
- **`REF-5305` — Presence & Exit Animations (`packages/core/src/AnimatePresence/`)**
  - Build `AnimatePresence` (`mode: 'sync' | 'wait' | 'popLayout'`, `exitDurationMs`, `onExitComplete`) + `usePresence()` / `useIsPresent()` hooks that keep unmounting keyed children mounted until their exit animation completes.

### Epic E2: Native Gestures, Cursors & Scroll Mechanics
- **`REF-5306` — Cross-Device Gesture Recognizers (`packages/core/src/hooks/useGestures.ts` & `packages/core/src/GestureSurface/`)**
  - Implement unified `useGestures` hook and `GestureSurface` component: touch-ignoring hover (`pointerType !== 'touch'`), pointer + IME-safe keyboard tap (`Enter`/`Space`), focus tracking, and rAF-coalesced drag with velocity tracking and momentum throwing (`computeMomentumTarget`).
- **`REF-5307` — Magnetic & Zoning Cursor (`packages/core/src/MagneticCursor/`)**
  - Build `MagneticCursor` reacting to `[data-magnetic-target]` elements inside its stage or viewport, pulling magnetically toward targets and morphing width/height/border-radius to match hit-target bounds via rAF-coalesced CSS custom properties (zero React re-renders per `pointermove`).
- **`REF-5308` — Hardware-Accelerated Scroll-Linked Values (`packages/core/src/motion/scrollLinked.ts` & `packages/core/src/ScrollLinkedStage/`)**
  - Implement `useScrollProgress`, `mapScrollRange`, and `ScrollLinkedStage` binding window, container, or target-element scroll progress (with configurable viewport offsets and sticky pinning) to CSS custom properties (`--prism-scroll-progress`, blur intensity, parallax offset, progress bar scale).
- **`REF-5309` — 3D Depth & Perspective FX (`packages/core/src/SpatialDepthDeck/`)**
  - Build `SpatialDepthDeck` supporting GPU-accelerated 3D `perspective` / `preserve-3d` layering patterns (`spin-blur`, `depth-deck`, `deeper-elements`) with rAF-coalesced pointer tilt, active card focus, and calm reduced-motion fallback.

### Epic E3: Animated Text, Numbers & Media Patterns
- **`REF-5310` — Animated Number Readouts (`packages/core/src/AnimateNumber/`)**
  - Build `AnimateNumber` smoothly interpolating and rolling changing numeric values with `tabular-nums`, optional prefix/suffix/currency/dB formatting, spring interpolation, and zero layout shift.
- **`REF-5311` — Split-Text Mask & Resize Reveals (`packages/core/src/SplitTextReveal/`)**
  - Build `SplitTextReveal` breaking headlines/labels into `chars`, `words`, or `lines` with masked reveal sweeps (`overflow-hidden` + staggered compositor transforms), `ResizeObserver` adaptation, and accessible `aria-label` text preservation.
- **`REF-5312` — SVG Path Drawing & `viewBox` Animation (`packages/core/src/SvgPathAnimator/`)**
  - Build `SvgPathAnimator` animating SVG `stroke-dashoffset` (`pathLength`) and smoothly interpolating `viewBox` coordinates (`[x, y, w, h]`) with presets (`checkmark`, `ring`, `sparkline`, `prism-loader`) inside `prism-contain-box`.
- **`REF-5313` — 2D / 3D Transitioning Galleries & Carousels (`packages/core/src/MorphingMediaGallery/`)**
  - Build `MorphingMediaGallery` morphing media items smoothly between `grid-2d`, `carousel-3d`, `coverflow-3d`, and `detail` views with swipe/drag momentum and full keyboard navigation.

### Epic E4: Motion Design System & Performance Tooling
- **`REF-5314` — Semantic Motion Theme (`packages/core/src/motion/motion.theme.ts`)**
  - Define `MOTION_THEME` and `createMotionTheme()` with the 5 canonical purpose-named transition tokens: `snap`, `ui`, `gentle`, `lively`, and `ambient`, each exposing spring config, compiled CSS `linear()` curve, duration, and calm opacity fallback.
- **`REF-5315` — Calm Reduced-Motion Mode (`packages/core/src/motion/MotionConfigProvider.tsx`)**
  - Implement `MotionConfigProvider` (`reducedMotion: 'user' | 'calm' | 'always' | 'never'`, `theme`) and `useMotionConfig()`, stripping spatial transforms under `'calm'` mode while preserving subtle opacity fades (`data-refractor-motion="calm"`).
- **`REF-5316` — Visual Timeline & Transition Editor (`packages/core/src/MotionStudio/`)**
  - Build `MotionStudio` allowing live visual tuning of `stiffness`, `damping`, `mass`, and semantic token presets with an interactive SVG spring curve graph, live animated glass preview, and copyable TypeScript/CSS `linear()` code export.
- **`REF-5317` — Render-Cost Performance Auditing (`packages/core/src/motion/motionScore.ts` & `packages/core/src/MotionPerformanceDoctor/`)**
  - Implement static source auditor (`auditMotionSource`) + runtime frame profiler (`evaluateFrameTimings`, `computeMotionScore`) and `MotionPerformanceDoctor` UI component grading animation cost (0–100, A–F) and flagging layout-thrashing properties (`width`, `height`, `top`, `left`, `margin`) and stacked blur bottlenecks.

## Release `v1.54.0` — Optical Material Engine, Dynamic Theming & GPU Guardrails

### Epic E5: Optical Material & Dynamic Theming Engine
- **`REF-5401` — Adaptive Contrast & Luminance Sensing (`packages/core/src/utils/opticalMaterial.ts` & `packages/core/src/AdaptiveContrastGlass/`)**
  - Implement `computeRelativeLuminance`, `resolveAdaptiveInkMode`, and `AdaptiveContrastGlass` sampling backdrop brightness/color to automatically flip foreground text, icons, and inner bevels between light and dark ink modes for guaranteed WCAG AA legibility.
- **`REF-5402` — Optical Material Presets (`packages/core/src/OpticalMaterialSurface/` & `refractor.css`)**
  - Define `OPTICAL_MATERIAL_PRESETS` (`wafer`, `lens`, `prism`) with centralized `ior`, `blurPx`, `thicknessPx`, `dispersion`, and `tintOpacity` tokens, CSS material classes, and `OpticalMaterialSurface` component.
- **`REF-5403` — Ambient Wallpaper / Accent Extraction (`packages/core/src/AmbientAccentExtractor/`)**
  - Implement `extractDominantAccents` + `useAmbientAccent` + `AmbientAccentExtractor` pulling primary/secondary accent hues from palette swatches, CSS gradients, or canvas image data to dynamically tint glows, focus rings, and rim lighting in real time.
- **`REF-5404` — Global Density & Scale Modes (`PrismThemeProvider`, `theme/types.ts`, `refractor.css`)**
  - Add `density?: 'compact' | 'comfortable' | 'touch'` to `PrismThemeProvider`, emitting `data-refractor-density` and density scale CSS tokens (`--prism-density-scale`, `--prism-hit-target-min`, `--prism-space-unit`, `--prism-radius-scale`, `--prism-border-thickness`).

### Epic E6: GPU & Shader Performance Guardrails
- **`REF-5405` — Single-Context WebGL / Shader Pooling (`packages/core/src/utils/shaderPool.ts`)**
  - Build `OpticalShaderPool` singleton (`getSharedShaderPool`, `usePooledOpticalShader`) rendering multiple glass refraction/caustic/ripple surfaces via one shared offscreen WebGL context and 2D blit targets to prevent browser WebGL context exhaustion.
- **`REF-5406` — Automatic Tiered Fallbacks (`packages/core/src/utils/gpuGuardrails.ts`)**
  - Implement `detectGpuCapabilityTier`, `stepDownGpuTier`, and `useGpuPerformanceGuardrail` gracefully degrading `'webgl-refraction'` → `'css-backdrop'` → `'flat-opaque'` on low-power devices, battery-saver, reduced-motion, or sustained frame drops.
- **`REF-5407` — Viewport & Focus Shader Pausing (`packages/core/src/hooks/useViewportVisibilityPause.ts`)**
  - Implement `useViewportVisibilityPause` combining `IntersectionObserver`, `document.visibilitychange`, and window blur/focus listeners so off-screen and background-tab shaders/gradients stay paused.
- **`REF-5408` — Sub-Pixel & DPR Scaling (`packages/core/src/hooks/useDprMetrics.ts`)**
  - Implement `snapToDevicePixel`, `getHairlineWidthPx`, and `useDprMetrics` locking hairlines, borders, and shader uniforms to `window.devicePixelRatio` with live DPR change detection.

## Release `v1.55.0` — Accessibility Resilience, Architecture DX & Sensory Feedback

### Epic E7: Accessibility (A11y) & Resilience
- **`REF-5501` — Reduced-Transparency & High-Contrast Modes (`PrismThemeProvider`, `useA11yPreferences`, `refractor.css`)**
  - Honor OS `prefers-reduced-transparency: reduce` and `prefers-contrast: more` automatically (plus explicit `PrismThemeProvider` overrides), swapping translucent glass for solid high-contrast surfaces and crisp `2px` borders.
- **`REF-5502` — Roving Tabindex & Keyboard Navigation Engine (`packages/core/src/hooks/useRovingTabIndex.ts`)**
  - Implement `useRovingTabIndex` with horizontal/vertical/grid arrow navigation, `Home`/`End`, timed typeahead search, `Escape` dismissal, wrap-around, and disabled item skipping.
- **`REF-5503` — Focus-Visible Prismatic Rings (`packages/core/src/FocusPrismaticRing/` & `refractor.css`)**
  - Add `.prism-focus-prismatic` double-ring `:focus-visible` indicator (inner dark keyline + outer luminous halo) and `FocusPrismaticRing` wrapper guaranteed visible over bright and dark glass.
- **`REF-5504` — Screen-Reader Live Regions (`packages/core/src/LiveAnnouncerRegion/`)**
  - Build `LiveAnnouncerProvider`, `useLiveAnnouncer`, and `LiveAnnouncerRegion` with dedicated `polite` and `assertive` channels, duplicate-text nudging, and clear-on-unmount cleanup.

### Epic E8: Architecture & Developer Experience (DX)
- **`REF-5505` — Headless Logic / Glass Skin Separation (`packages/core/src/headless/primitives.ts`)**
  - Implement headless behavioral hooks (`useHeadlessButton`, `useHeadlessDisclosure`, `useHeadlessTabs`, `useHeadlessMenu`) returning pure ARIA/keyboard/state prop getters decoupled from glass styling.
- **`REF-5506` — Polymorphic Composition (`packages/core/src/Slot/`)**
  - Build `Slot` component enabling the `asChild` pattern to merge refs, event handlers, `className`, `style`, and `xstyle` directly onto custom child elements with zero wrapper `<div>` soup.
- **`REF-5507` — Compound Component APIs (`packages/core/src/OpticalCard/`)**
  - Build `OpticalCard` compound API (`OpticalCard.Root`, `OpticalCard.Header`, `OpticalCard.PrismEdge`, `OpticalCard.Body`, `OpticalCard.Footer`) with shared material/density context.
- **`REF-5508` — Strict TypeScript Contracts & Token Autocomplete (`packages/core/src/utils/strictContracts.ts`)**
  - Export discriminated union prop contracts (`AccessibleIconActionProps`), literal token types (`OpticalMaterialTier`, `MotionTokenName`, `ThemeDensityMode`, `SemanticColorToken`), and runtime assertion helpers with zero `any`/`unknown`.

### Epic E9: Sensory & Tactile Feedback
- **`REF-5509` — Synthesized Micro-Audio Engine (`packages/core/src/sensory/microAudio.ts`)**
  - Implement opt-in Web Audio API procedural sound engine (`playGlassClick`, `playHoverTick`, `playChimeConfirm`, `playDetentTick`, `playErrorThud`, `useMicroAudio`) with zero external audio assets and full cleanup.
- **`REF-5510` — Haptic Feedback Hooks (`packages/core/src/sensory/haptics.ts`)**
  - Implement `triggerHaptic(pattern)` and `useHaptics()` (`light`, `medium`, `rigid`, `selection`, `success`, `error`) using `navigator.vibrate` with graceful unsupported-device and reduced-motion fallbacks.
