---

## 1. Evaluation Rubric (4-Axis Equal Weight)

| Axis | Weight | Criteria |
| --- | :---: | --- |
| **Visual Craft & Optical Fidelity** | 25% | Authentic optical-glass depth hierarchy (`prism-slab`, `prism-crystal`, `prism-well`, `prism-emerald`), calibrated Light/Dark contrast (`>= 4.5:1`), scannable typographic rhythm, zero raw color literals. |
| **Interaction & Workflow Depth** | 25% | Genuine stateful workflows (live chat appending, step progression, cart/coupon math, diff approvals, file switching, swipe actions, form validation) rather than static mockups. |
| **Responsive Ergonomics (Web / Tablet / Mobile)** | 25% | Adapts seamlessly across Desktop, Tablet (`768px` / `834px`), and Mobile (`360px`–`412px`) with `0px` horizontal overflow, touch-friendly hit targets, and live interactive device-frame previewing. |
| **Code Completeness & Modern Best Practices** | 25% | Standalone, copy-pasteable React 19 + strict TypeScript TSX code (`0` `any` / `0` `unknown`), accessible ARIA semantics, keyboard/IME safety, and direct `@refractor-ui/core` composition. |
